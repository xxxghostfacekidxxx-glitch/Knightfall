Install on your phone

Android: Open this page in Chrome, choose Install Chaosphere above. If a prompt is unavailable, use the Chrome ⋮ menu and tap Install app or Add to Home screen.

iPhone: Open in Safari, tap Share, then Add to Home Screen.

Desktop: Use the browser's install icon or its app-install menu.
