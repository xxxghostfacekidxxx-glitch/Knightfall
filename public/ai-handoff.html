Each of you can generate your own revocable AI connection for a supported ChatGPT Action. Each key expires after 90 days, and the site stores only its hash. The assistant can read current tasks, add tasks, change status, and post handoff notes; it cannot access other Knightfall data.

How Ronnie and Samantha connect their separate ChatGPT assistants
        
    
          
  1. Each person signs in to Knightfall and generates a separate key here. Do not share keys with each other.
    2. 
          
  2. In a private ChatGPT configuration that supports custom Actions, import https://ash-fall.com/ai-bridge-openapi.json or paste its schema.
    3. 
          
  3. Set the Action authentication to API Key → Bearer, and store your own key in that authentication field only.
    4. 
          
  4. Copy the assistant instructions into the assistant's configuration. Test the getHandoffSnapshot action; confirm it displays this shared list.
    5. 
          
  5. When you ask your assistant about Knightfall work, it can read the current list and write confirmed updates. Both people will see the updates here automatically.
    6. 
        

        
ChatGPT availability (November 2026): Personal Free, Go, Plus and Pro accounts cannot create new custom GPTs. These Action steps only work for existing editable GPTs or workspaces that still support Actions. Otherwise use the live shared website and copyable packet. Knightfall cannot silently access either person's private ChatGPT conversations.

      

    

    

      
GUIDE FOR SAMANTHA + HER GPT
The creator's survival kit

        
      

      
Sam, you do not need to know coding to help build Knightfall. Start with an art idea, an issue you noticed, or a small test. Your GPT can explain the steps, draft work, suggest free tools and add the results to this board when it has an authorized connection. No imaginary superpowers required.

Easy workflow for Samantha and her GPT
        
    
          
  1. Pick one project task. Filter by workstream or priority, or search for a game, art asset or problem.
    2. 
          
  2. Check where it stands. Read the source link, verification level, next action and any blocker. "Needs review" is not the same as "nothing exists."
    3. 
          
  3. Ask for simple steps. Have your GPT explain what tool to open, what to click, and what success looks like. Use Foundry for building and Arsenal for finding references.
    4. 
          
  4. Record what actually happened. Change the status only when justified, add a blocker or next step, and leave a short dated handoff note for Ronnie.
    5. 
          
  5. Respect permissions. Creating local artwork and proposing code are okay. Publishing, changing accounts, granting roles, spending money or deploying requires separately authorized access.
    6. 
        

        
Neither assistant can inspect the other's private conversation without a supported, explicitly connected integration. The shared list and notes are the coordination record.
