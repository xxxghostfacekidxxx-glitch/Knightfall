# Chaos Cartridge brand assets

- `chaos-cartridge-logo.svg`: master arcade emblem / wordmark.
- `/icons/chaos-cartridge.svg`: compact crowned glitch-cartridge app and browser icon.
- `/icons/chaos-cartridge-maskable.svg`: safe-area variant for installed apps.
- `archive/knightfall-ember.svg`: preserved original ember/flame icon, before the Chaos Cartridge branding update.

Palette: midnight `#07070b`, hot pink `#ff27ce`, acid green `#c6ff45`, metallic charcoal. Tagline: **PLAY DIRTY**.

Use the master logo for arcade landing pages and promotional placements; use the compact icon for favicons, PWA installs, and small navigation surfaces.
