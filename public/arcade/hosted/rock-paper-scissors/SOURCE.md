# Rock Paper Scissors native adaptation

- Reviewed upstream source: https://github.com/sausi-7/games, path games/board/rock-paper-scissors/index.html.
- The upstream build depends on Phaser and scene files; those runtime dependencies and assets were not imported.
- This cabinet is a fresh Knightfall-native implementation of the public-domain game rules. No upstream source code, sprites, fonts, audio, or other assets are redistributed.
- Dependencies: inline HTML/CSS/JavaScript only; no network requests or CDN.
- No account credentials, Cinders, or server score API access. Match scores stay in memory.
