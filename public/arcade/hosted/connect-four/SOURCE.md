# Connect Four native adaptation

- Reviewed upstream source: https://github.com/kenrick95/c4.
- Upstream is MIT-licensed but uses a TypeScript/Yarn build pipeline. Its code and assets were not copied into this cabinet.
- This is a fresh Knightfall-native implementation of the generic Connect Four rules with a local minimax CPU, original UI/CSS, and no third-party assets.
- Dependencies: inline HTML/CSS/JavaScript only; no network requests or CDN.
- No account credentials, Cinders, or server score API access. Matches are local only.
