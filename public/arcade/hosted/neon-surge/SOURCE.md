# Neon Surge — Ash-Fall / Knightfall Arcade
Original author: **nnnnnnnnnke**.
Upstream: https://github.com/nnnnnnnnnke/neon-surge

License: MIT (preserved in `LICENSE`).

Changes: translated Japanese UI, accessibility labels and gameplay instructions into English; retained the original game engine, shaders, audio synthesis and visual effects.

Dependencies: Three.js r186 and postprocessing addons via jsDelivr, optional web fonts via Google Fonts. A current WebGL2 browser and internet access to load the CDN are required. **Not yet fully offline.**

This is an independent game. No Geometry Wars proprietary assets, music or game files are included.
