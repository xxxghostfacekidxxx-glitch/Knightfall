# Dino Run: Ash-Fall Edition source notice

This cabinet adapts the single-file Dino Run game from [mashukui/web-games](https://github.com/mashukui/web-games), originally at `dino-run/index.html`, and uses that project's shared `i18n.js` language layer.

- Upstream license: MIT. The complete upstream license is retained in `LICENSE.txt` and at `/arcade/hosted/WEB-GAMES-LICENSE.txt`.
- Upstream source: https://github.com/mashukui/web-games
- Changes by Knightfall: Ash-Fall theme and palette, removed the unrelated third-party downloader link and analytics loader, added Chaos Cartridge/records navigation, account leaderboard submission, account-best-score loading, and responsive status text.
- Art and audio: the game draws its dinosaur, obstacles, and scenery with Canvas/vector primitives; no external game art, sound files, or remote runtime dependencies were copied.
- The MIT license applies to the upstream code and shared language layer. Knightfall's modifications are identified above; the original author is not responsible for this adaptation.
