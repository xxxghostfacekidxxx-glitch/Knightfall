# Ash-Fall mini-game adaptations

These games are original Ash-Fall implementations inspired by the genre and mechanics described by the listed open-source projects. They do not copy upstream source files or artwork. The referenced projects are retained for research and attribution, not represented as code imports.

- Particle Clicker research/incremental genre reference: https://github.com/particle-clicker/particle-clicker (MIT upstream; see upstream license for its own source).
- Cube Composer puzzle/logic reference: https://github.com/sharkdp/cube-composer (MIT upstream).
- SkiFree downhill avoidance reference: https://github.com/justinbarr/ski-free (license not verified; no upstream code or assets used).
- Ball and Wall paddle-breakout reference: https://github.com/budnix/ball-and-wall (MIT upstream code; its Pegasus artwork has separate paid licensing and is not used).

All artwork in this implementation is rendered with Canvas primitives. The game source in this directory is authored for Knightfall and does not bundle third-party runtime dependencies.
