# Balloon Pop source notice

This cabinet adapts the self-contained Canvas game `balloon-pop/index.html` from [mashukui/web-games](https://github.com/mashukui/web-games) and uses the shared `i18n.js` language layer already hosted under `/arcade/hosted/`.

- Upstream license: MIT. The complete license is retained in `LICENSE.txt` and `/arcade/hosted/WEB-GAMES-LICENSE.txt`.
- Upstream source: https://github.com/mashukui/web-games
- Knightfall changes: Ash-Fall color palette and navigation, removed the unrelated third-party downloader link and analytics loader, added authenticated best-score loading, account leaderboard submission, status feedback, and a direct issue-report link.
- Artwork and sound are generated by the game's own Canvas/Web Audio code. No external game assets or runtime dependencies were copied.
