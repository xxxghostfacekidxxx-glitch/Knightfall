ESOTERIC SCRIPT TOOL / LATER RECEPTION

Theban Alphabet Studio

Encode Latin letters as Theban glyphs or use the glyph keyboard to decode. The alphabet was printed in Trithemius's Polygraphia (1518), not used as a pharaonic Egyptian writing system. This tool follows the later 23-glyph convention: J shares I, U shares V, and W uses VV. Capitalization and those letter distinctions cannot be recovered automatically.

It is a substitution cipher, not a language translation or secure encryption. Nothing is sent to a translation service. Literal brackets and backslashes are escaped in portable tokens.

Encode text

Plain-text tokens are portable; visual glyphs use the credited online SVG images. SVG export retrieves and embeds glyph artwork; initial retrieval requires internet access. If retrieval fails, no incomplete file is exported. Successful files contain the glyphs without external links.

Decode with the glyph keyboard

Tap glyphs, add spaces, or paste portable tokens from the encoder. Output uses I and V for shared letters.

Reference: Trithemius, 1518 facsimile. Glyph artwork by Fuzzypeg, public-domain Wikimedia Commons files. Glyph source collection. If artwork is unavailable, readable glyph-letter labels and the original reference remain available.
