Will site updates still work?

Yes. Knightfall remains hosted on Cloudflare Pages and Workers. Game art, messaging, forums, and Creator Foundry changes update through the web. Only changes to the Android wrapper itself require another signed APK.

Security note: Only install a Knightfall APK when it is explicitly identified as a signed release on this official page. Never install an APK from a random chat attachment or impersonating website.
