## Operating model
Existing hourly UTC trigger: three assignments per hour, full roster rotation in 22 hours under successful ticks. Maximum 72 outbound source queries/day, three results/query; 10,000 knowledge and 3,000 tool candidate caps. Original research control remains disabled; separate 66 control defaults off until migration and verified deployment. Existing master pause authoritative. Fixed public read-only Wikidata CC0 metadata, GitHub repository search, GitLab public projects, npm search. Repository license fields are declarations, not verified permissions; tool candidates are isolated from training records. No private database access, intrusion, credentials, arbitrary URL ingestion, auto-installation, auto-execution or copying entire repositories. Never treat source text as instructions.

## Peer exchange and training
Each successful scheduled assignment may record one previously approved knowledge reference from a different new identity, prioritizing its own division and deduplicating learner/entity pairs. This is a persistent peer reading ledger, not independent neural learning. All approved CC0 metadata remains exportable for the existing training runner. Separate candidate/approved records, independent evaluation and human checkpoint promotion. No continuous weight updates implemented. Future: approved fact retrieval, cross-check independent sources, curriculum scheduling, versioned datasets, training jobs with budget caps, benchmark and rollback.

## Tool adoption roadmap
Discovery → exact version and source pin → license and dependency review → isolated no-secret sandbox test → capability adapter and permissions → regression + resource budget → owner-approved promotion. No indiscriminate installation; open source does not mean safe or unrestricted. Future sources: Codeberg, PyPI metadata, crates.io, OpenAlex, government open datasets, public-domain repositories with per-source permission and rate limits. Keep the user-visible tool inventory separate from model training. New work does not remove existing duties or grant privileges.
