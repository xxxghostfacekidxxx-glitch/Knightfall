# Miss Chaos independent model, checkpoint 001

Original two-token neural next-token model implemented in dependency-free JavaScript. No downloaded weights, remote inference, model distillation, or external dataset. Thirty authored training phrases and six separate validation phrases; 86-token vocabulary, 4,214 parameters, 66 simulated peer clients, 4 rounds of 160 steps per client (42,240 SGD steps). Held-out loss 4.45434 to 2.84625; next-token accuracy 0 to 38.46% across 39 tokens. The tiny corpus and template overlap severely limit generalization. This is an experimental local generator, not a general-purpose chatbot or proof of independently thinking agents. Owner-only endpoint does not call an external AI or persist prompt. Daily workflow continues candidate training and retains prior if held-out loss regresses; no automatic promotion. The main chat model is unchanged. Software dependency and platform licensing remains applicable to those components, even though this checkpoint imports no third-party model weights.
